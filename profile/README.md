# UniverseDock

**UniDock — Your Dock to the Universe.**

UniverseDock is an extensible personal content and information platform.

It brings different kinds of content, sources, tools, and services together through a unified, plugin-based architecture.

## What is UniDock?

UniDock is designed as a personal information platform rather than a single-purpose reader.

It can connect:

* 📚 Books and reading
* 📰 RSS and articles
* 📺 IPTV and live channels
* 🎧 Audio and podcasts
* 🎬 Video
* 📄 Documents and web content
* 🤖 AI and agents
* 🔌 Plugins and integrations
* ☁️ Sync and storage
* ⚙️ Automation

## Architecture

UniDock is built around a few core concepts:

```text
Content
   ↓
Source → Processor → Storage
   ↓
Renderer / Player
   ↓
Workspace
   ↓
Automation / AI
```

The system is designed to be extensible through plugins and capabilities rather than tightly coupling every feature to the core application.

## Projects

The main project is currently under development.

* **UniDock** — The main personal content platform
* **UniDock SDK** — Plugin development SDK
* **UniDock Core** — Core runtime and capability system

More projects will be added as the architecture evolves.

## Philosophy

> **Your Dock to the Universe.**

UniDock is intended to provide one place to discover, collect, process, read, watch, listen to, and interact with information from different sources.

The project is designed with:

* PWA-first architecture
* Offline-first data access
* Plugin-based extensibility
* Capability-based permissions
* Cross-platform support
* Local-first data management
* Optional synchronization
* AI-assisted workflows
